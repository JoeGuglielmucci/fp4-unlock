The following Python function is supposed to merge overlapping intervals and return them sorted by start, but it has at least two bugs. Find every bug, explain each one in one sentence, then give the corrected function and five test cases including an empty list, a single interval, touching intervals like [1,3] and [3,5], nested intervals, and unsorted input.

def merge_intervals(intervals):
    if not intervals:
        return intervals
    intervals.sort(key=lambda x: x[1])
    merged = [intervals[0]]
    for current in intervals:
        last = merged[-1]
        if current[0] < last[1]:
            last[1] = max(last[1], current[1])
        else:
            merged.append(current)
    return merged
