"Speculative decoding speeds up large language model inference by using a small, fast draft model to propose several future tokens before the large target model is run. The draft model generates a short candidate sequence, often greedily or with a simple sampling policy, in a few cheap forward passes. The target model then processes the original prompt plus all proposed tokens in one forward pass, computing logits for every position. This lets it verify multiple draft tokens at once instead of generating one token per pass.

Verification preserves the target model’s output distribution by comparing the draft’s proposed tokens with the target’s probabilities. For each position, the algorithm accepts the draft token if the target model assigns it at least as much probability as the draft did; otherwise it rejects the token and samples a replacement from a corrected distribution that favors the target model’s choices. After the first rejected token, the remaining draft tokens are discarded. Because acceptance and resampling are defined to match the target model’s conditional probabilities, the final sequence has the same distribution as ordinary autoregressive decoding from the target model, even though the target model evaluated several positions in parallel.

In practice, speedup depends on how often the target model accepts draft tokens, the cost of running the draft model, the overhead of the extra verification pass, and the hardware’s ability to exploit batched positions. If the draft model is well aligned with the target and the task is predictable, many tokens are accepted and the target model’s expensive pass produces several outputs at once. If the draft is weak, the task is uncertain, or the draft/verification overhead is high, fewer tokens are accepted and the gain shrinks.
