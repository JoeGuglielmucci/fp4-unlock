"Speculative decoding speeds up large language model inference by using a small, fast draft model to propose several future tokens before the large target model is run. The draft model generates a short sequence of candidate tokens, usually one to eight, using its own cheap autoregressive steps. The target model then processes the original prompt plus all draft tokens in a single forward pass, producing a probability distribution for each position in the sequence.

Verification is done token by token. For each draft position, the target model’s distribution is compared with the draft model’s distribution. A rejection-sampling rule accepts the draft token when it is sufficiently likely under the target model; if it is rejected, the algorithm samples a replacement token from a corrected distribution that combines the target and draft probabilities and stops further speculation.
