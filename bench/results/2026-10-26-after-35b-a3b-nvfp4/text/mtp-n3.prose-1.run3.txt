   - *Target model verification:* The target model runs a single forward pass over the entire context plus all draft tokens simultaneously. It computes logits for each position, allowing parallel evaluation of the draft sequence.
   - *Distribution preservation:* Speculative decoding uses a rejection sampling step. For each draft token, the target model's probability is compared to the draft's probability. If the target model agrees (or samples a value that falls within the draft's probability mass), the token is accepted. Otherwise, a token is sampled from the target model's distribution at that position. This ensures the final output distribution matches the target model's exact distribution, maintaining mathematical correctness.

     1. Low acceptance rate (draft model diverges from target model, especially on complex/novel prompts)
     2. Memory bandwidth/latency bottlenecks (the target model's forward pass is already memory-bound, so parallelizing token evaluation doesn't scale linearly with compute savings)
