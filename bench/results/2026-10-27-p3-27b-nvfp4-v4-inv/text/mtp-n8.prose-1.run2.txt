"Speculative decoding speeds up large language model inference by using a smaller, faster draft model to propose several future tokens, then checking them with the large target model in a single forward pass. In ordinary autoregressive decoding, the target model must run once per generated token, so latency is dominated by repeated memory-bound passes. Speculative decoding changes this: the draft model generates a short candidate sequence, for example five tokens, using its own fast sampling. The target model then processes the original prompt plus all proposed tokens at once and computes the probability of each next token at every position. This lets the target model verify multiple candidates in the same time it would have taken to generate one token.

The key correctness property is that the final output distribution can be identical to standard target-model decoding. For each proposed token, the algorithm compares the draft probability with the target probability. If the target model strongly agrees, the token is accepted. If the target model disagrees, the token is rejected and a new token is resampled from a corrected distribution that favors the target model’s probabilities while avoiding tokens already accepted. This rejection-sampling step preserves the target model’s exact next-token distribution, so the generated text is statistically the same as if the target model had decoded alone.

In practice, speedup depends on how often the draft model’s proposals are accepted, the draft model’s latency relative to the target model, and the number of tokens verified per target pass. A good draft model that is much faster than the target and matches its preferences can reduce the number of target forward passes needed per output token.

The two most common reasons the speedup is smaller than hoped are low acceptance rates, often because the draft model is too small, poorly aligned, or the task is hard, and high draft overhead, where running the draft model or managing verification consumes enough time to erase the savings from fewer target passes
