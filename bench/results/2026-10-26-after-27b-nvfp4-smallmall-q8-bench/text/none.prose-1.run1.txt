"Speculative decoding speeds up large language model inference by using a small draft model to propose several future tokens before the large target model is run. The draft model generates k candidate tokens sequentially, which is cheap because it is small and can be run quickly. The target model then processes the original prompt plus those k candidates in a single forward pass, producing logits for every position. This lets it verify all proposed tokens at once rather than waiting for one token at a time.
