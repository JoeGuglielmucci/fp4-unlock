Speculative decoding speeds up large language model inference by using a small draft model to propose several future tokens before the large target model checks them. The draft model is usually cheap and starts from the same prompt, generating a short sequence of candidate tokens. Because the draft model is often fast, it can produce many tokens in parallel, but the target model is still responsible for quality.

The target model then verifies the draft token in one forward pass. In the target model, the draft tokens are appended to the prompt, and the model computes the next-token distribution at each position. This lets the target model evaluate many tokens at once, without needing the same number of sequential forward passes as ordinary autoregressive decoding.
