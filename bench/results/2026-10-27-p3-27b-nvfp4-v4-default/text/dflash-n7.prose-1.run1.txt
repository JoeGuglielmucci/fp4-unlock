"Speculative decoding speeds up large language model inference by using a small, fast draft model to propose several future tokens before the large target model is run. The draft model generates a short candidate sequence, often greedily or with a simple sampling policy, because it is much cheaper to evaluate. The target model then processes the original prompt plus the proposed tokens in a single forward pass and computes its own probabilities for every position in that sequence. This lets the target model verify multiple candidate tokens at once instead of generating them one by one, which is the usual bottleneck in autoregressive decoding.

The key trick is a rejection test that preserves the target model’s output distribution. For each proposed token, the method compares the target probability with the draft probability. If the target model strongly agrees, the token is accepted. If it disagrees, the token is rejected and a new token is sampled from a corrected distribution that favors the target model’s probabilities while accounting for the draft’s proposal. Because this correction is mathematically equivalent to sampling from the target model alone, the final text has the same distribution as normal decoding, even though some tokens were produced by the draft model.

A good draft model that is cheap and well aligned with the target can yield large gains, especially when the target model is large and inference is compute-bound.
