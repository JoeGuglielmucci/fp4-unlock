Draft:
Speculative decoding accelerates large language model inference by using a smaller, faster draft model to propose a short sequence of candidate tokens, often called a draft, before the large target model is run. The draft model is cheap to execute, so it can generate several tokens sequentially in a small amount of time. The target model then takes the original prompt plus the proposed draft and performs a single forward pass over the whole sequence. Because transformer inference can process multiple positions in parallel, this one pass yields the target model’s probability distribution for the first draft token, the second draft token conditioned on the first, and so on.

The key trick is verification. The target model accepts draft tokens only when they are consistent with its own distribution. For each position, it compares the draft token’s probability under the target model with the probability that would have been assigned if the target model had generated that token directly. If the target model would have chosen the token with sufficient likelihood, it is accepted; otherwise, the first rejected token is replaced by a token sampled from a corrected distribution that favors the target model’s preferences. This rejection-sampling step is what preserves the output distribution: every token ultimately returned is sampled from the same conditional distribution the target model would have produced in ordinary autoregressive decoding, so the final text is statistically identical, not merely similar.

In practice, speedup depends on how many draft tokens are accepted before a rejection, the relative cost of the draft and target models, and the efficiency of the target model’s parallel verification pass. A good draft model should be fast and aligned with the target model’s behavior, while the draft length should be long enough to amortize the target pass but short enough to avoid wasting computation on rejected tokens.
