"Speculative decoding speeds up large language model inference by using a small draft model to propose several future tokens before the large target model is run. The draft model generates k candidate tokens sequentially, using its own cheap forward passes. The target model then processes the original prompt plus those k draft tokens in a single forward pass, producing logits at every position. This lets it verify all proposed tokens at once instead of waiting for one token per target pass.

Verification is done position by position. At each draft position, the target model compares its probability for the proposed token with the draft model’s probability. If the target probability is at least as large, the token is accepted. If it is smaller, the token is accepted with probability p_target/p_draft; otherwise a new token is sampled from a corrected distribution that combines the target and draft probabilities.
