"Speculative decoding speeds up large language model inference by using a small, fast draft model to propose several future tokens before the large target model is run. The draft model generates a short candidate sequence, often greedily or with a simple sampling policy, in a few cheap forward passes. The target model then processes the original prompt plus the proposed tokens in one forward pass, computing logits for every position in that sequence. This lets it verify multiple draft tokens at once instead of generating them one by one.

The key trick is a rejection test that preserves the target model’s normal output distribution. For each proposed token, the method compares the target probability with the draft probability. If the target model is at least as confident as the draft, the token is accepted. If not, the token is rejected and a new token is sampled from a corrected distribution that favors the target model’s probabilities while accounting for the draft’s proposal. Because this correction is derived from the target and draft distributions, the final sequence has the same distribution as if the target model had decoded alone, assuming the same random seed and sampling parameters.

In practice, speedup depends on how many draft tokens are accepted before a rejection, the relative cost of the draft and target models, and the efficiency of the target’s parallel verification. A good draft model that matches the target’s preferences can accept long runs, while a poor one causes frequent rejections. The two most common reasons the speedup is smaller than hoped are a low draft acceptance rate and the overhead of running the draft model plus the target verification pass, especially when the target model is already fast or the batch size is large."
